# newsboat_send

A simple bash script that uses [Newsboat 2.36](https://newsboat.org/),
[Pandoc 3.1](https://pandoc.org), and [Mutt 2.2](http://www.mutt.org/) to
read the [SQLite](https://sqlite.org) database generated by newsboat,
convert it to plain text using pandoc, and then send an email message to a
given user using mutt.

## Setup

1. These instructions presuppose that `newsboat`, `pandoc`, `mutt`, and `sqlite` are installed on your (Linux) system.

2. You should also have run `newsboat` at least once (for instructions on setting up `newsboat` see their home page).

3. Make sure to create the directory `~/.newsboat/logs/` if it is not created already.

## Usage

Simply execute:

		newsboat_send
        
alternately:

		bash newsboat_send

## Running as an (ana)cronjob

To run as a daily (ana)cronjob, add a wrapper (e.g., `custom-newsboat`) to `/etc/cron.daily/`.
