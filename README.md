# newsboat_send

A simple bash script that uses [Newsboat 2.36](https://newsboat.org/),
[Pandoc 3.1](https://pandoc.org), and [Mutt 2.2](http://www.mutt.org/) to
read the [SQLite](https://sqlite.org) database generated by newsboat,
convert it to plain text using pandoc, and then send a message to a given
user using mutt.

## Setup

These instructions presuppose that `newsboat`, `pandoc`, `mutt`, and `sqlite` are installed on your (Linux) system.

You should also have run `newsboat` at least once (for instructions on setting up `newsboat` see their home page).

1. Edit the file [`newsboat_send`](https://github.com/lmcmicu/newsboat_send/blob/main/src/newsboat_send) and set the variable `USER` to the email address (or Linux username) that you would like emails to be sent to.

2. Created a new directory `~/.newsboat/logs/`

## Usage

Simply execute:

		newsboat_send
        
alternately:

		bash newsboat_send

## Running as an (ana)cronjob

To run as a daily (ana)cronjob, add a wrapper (e.g., `custom-newsboat`) to `/etc/cron.daily/`.
