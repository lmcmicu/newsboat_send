# newsboat_send

A simple bash script that uses [Newsboat 2.36](https://newsboat.org/),
[Pandoc 3.1](https://pandoc.org), and [Mutt 2.2](http://www.mutt.org/) to
read the [SQLite](https://sqlite.org) database generated by newsboat,
convert it to plain text using pandoc, and then send a message to a given
user using mutt.

## Running as an (ana)cronjob

To run as a daily (ana)cronjob, add a wrapper (e.g., `custom-newsboat`) to `/etc/cron.daily/`.
